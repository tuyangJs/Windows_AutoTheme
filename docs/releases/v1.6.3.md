## 修复

- 修复获取城市失败后按钮持续转圈、城市输入框无法使用的问题；失败或超时后保留原有城市，恢复操作。[#32](https://github.com/tuyangJs/Windows_AutoTheme/pull/32)
- 修复手动城市搜索不可用，改用 Open-Meteo；修复 HTTP 插件前后端响应体协议不一致造成的读取卡住。[#32](https://github.com/tuyangJs/Windows_AutoTheme/pull/32)
- 修复时间偏差设为 0 分钟后回跳的问题，支持保存 0～60 分钟。[#32](https://github.com/tuyangJs/Windows_AutoTheme/pull/32)
- 修复在磁盘根目录创建 `logs` 文件夹及 `app.log.log` 双重扩展名的问题，日志继续保存在系统标准的应用日志目录。[#30](https://github.com/tuyangJs/Windows_AutoTheme/pull/30)

## 构建与交付

- Windows x64 安装包由 GitHub Actions 自动测试、构建，并附带 `SHA256SUMS.txt` 校验文件。
- 统一应用版本号，固定 Rust 依赖解析结果；版本标签与应用版本不一致时停止构建。
- 支持推送版本标签或手动运行工作流生成草稿 Release，确认后再发布。

## 安装

下载 `AutoThemeMode_1.6.3_x64-setup.exe` 安装。此 GitHub 安装包未配置代码签名；Microsoft Store 版本仍通过商店单独发布。
